# ST34 Resistome Analysis

Computational analysis of antimicrobial resistance gene diversity and multidrug resistance patterns in Salmonella enterica Sequence Type 34 (ST34).

## Project Overview
This project investigates resistome architecture in 937 publicly available ST34 genomes using computational genomics and bioinformatics workflows.

## Major Analyses
- AMR gene prevalence
- Resistance class distribution
- Multidrug resistance analysis
- Resistance gene burden
- Gene co-occurrence analysis

## Bioinformatics Tools Used
- QUAST
- MLST
- SISTR
- ResFinder
- Python
- pandas
- NumPy
- matplotlib
